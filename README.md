# 🧋 搖搖圖鑑 ShakeDex

用寶可夢圖鑑的概念，收集並評分喝過的每一杯手搖飲。

每杯飲料都用同一套標準評分（風味、甜度平衡、口感、CP 值），網站會自動算出總分、店家平均與回購率，並依飲料顏色、冰塊和配料畫出專屬的杯子插圖。

## 功能

- **圖鑑首頁**：搜尋、依分類或店家篩選、依分數／CP 值／價格排序
- **店家頁**：店家平均分、回購率、該店喝過的飲料排行
- **飲品頁**：大張杯子插圖、四項評分雷達圖、短評、上一杯／下一杯
- **評分標準頁**：評分維度與所有選項，內容直接由 `data/options.json` 產生

## 這個專案怎麼繼續做？

所有規則都寫在 [`AGENTS.md`](AGENTS.md)。AI 協作者讀完後，只要使用者說一句：

> 新增一杯迷客夏的珍珠鮮奶，微糖去冰，65 元，風味 4、平衡 5、口感 5、CP 3，會回購，短評：珍珠很香，鮮奶很濃。

AI 就會依照 SOP 在 `data/drinks.json` 新增一筆資料、跑驗證腳本，網站自動出現新的圖鑑卡片，不需要改任何 HTML。
